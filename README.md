# Buckshot Roulette · Minecraft 基岩版牌桌

把《恶魔轮盘》(Buckshot Roulette) 搬进 Minecraft Bedrock：一张可放置的牌桌，坐下就能打完一局——九种道具、装填与回合状态机、恶魔 AI、存档与排行榜、镜头演出。

当前版本 **v1.2.36**，适配 **Minecraft Bedrock 1.26.40 及以上**。

> 本仓库只发布可直接安装的附加包，不含构建脚本。

## 下载与安装

下载 `RouletteTable(26.40+).mcaddon`，用游戏直接打开，行为包和资源包会一起导入。

也可以手动安装：

| 文件夹 | 放到 |
|---|---|
| `RouletteTable_BP/` | `behavior_packs/` |
| `RouletteTable_RP/` | `resource_packs/` |

进世界后启用这两个包，在物品栏里找到「轮盘牌桌」放下即可。

**不需要开启 Beta APIs 实验**——脚本声明的是稳定模块 `@minecraft/server 2.9.0` / `@minecraft/server-ui 2.0.0`。

## 怎么玩

放下牌桌，靠近桌面点击入座。桌面会显示双方电量、道具槽、弹仓和当前持枪状态。

每回合装填若干实弹与空包弹，按顺序使用道具、选择目标开枪。九种道具：放大镜、啤酒、手铐、手锯、香烟、肾上腺素、逆变器、手机、过期药品。

## 兼容性

| 项 | 值 |
|---|---|
| 目标版本 | Minecraft Bedrock 1.26.40+ |
| `min_engine_version` | `[1, 26, 40]` |
| `@minecraft/server` | `2.9.0`（稳定） |
| `@minecraft/server-ui` | `2.0.0`（稳定） |
| Beta APIs 实验 | 不需要 |

`min_engine_version` 是下限而非上限，理论上是向上兼容的；但完整实机验收只在 1.26.40 上做过，1.26.60 尚未逐项验证。

## 版本记录

- **v1.2.36** — 生成的 JSON 改为紧凑格式：`.mcaddon` 712 KB → 603 KB，解压后 8.44 MiB → 2.06 MB。功能与外观无变化。
- **v1.2.35** — 默认构建回退为单人功能版，多人桌不再打进包。

## 已知限制

- 多人桌（5×5 四座位）的代码仍保留在开发端，但本版本不包含、未启用，也没有完成实机验收。
- 单人无尽模式的对局状态存在世界存档里；本版本不含多人，不存在多人存档问题。
